경험한 향으로,
추천을 함께 살펴봐요.

대학 머신러닝 프로젝트의 로컬 추천 평가입니다. 직접 사용하거나 시향한 향수만 평가해 주세요. 미경험은 낮은 평점이 아닙니다.

1. 참여 안내

평점은 프로젝트 개발 또는 평가에 쓰일 수 있습니다. 이름·전화번호·이메일은 요구하지 않습니다. 참여는 자발적이며 중단해도 불이익이 없습니다.

운영 방침 확인 중

가입 때 한 번만 표시되는 삭제 코드를 반드시 따로 보관하세요. 서버에는 코드 해시만 저장하며, 코드를 분실하면 개별 삭제가 제한될 수 있습니다. 이 브라우저의 ‘내 응답 삭제’ 또는 아래 코드로 철회할 수 있습니다. 쿠키 삭제·기기 변경 시 동일인 확인이 어려우므로 중복 참여하지 말아 주세요. 제품명 칸에도 연락처를 쓰지 마세요.

삭제 코드로 응답 삭제

2. 경험한 향수 평가

서로 다른 정확한 제품 5개가 필요합니다. 가능하면 추천 전에 8~10개를 남겨 주세요. 저장한 경험 상품은 추천 후보에서 제외합니다. 이 화면은 Offline 정확도 평가가 아닙니다. 원본에 농도 표기가 없으면 임의 추정하지 않습니다.

경험한 제품이 검색되지 않나요?

미등록 제품은 검토용으로만 저장하며 추천 Support로 연결하지 않습니다.

3. 추천 모드 선택

개인화는 7점 이상 선호·3점 이하 비선호·중간 중립으로 처리합니다. 추천 이유는 실제 특징에서만 생성합니다.

Unified는 순위 백분위 결합입니다. 모드별 점수는 직접 비교할 수 없으며 정확도 개선이 검증된 모델이 아닙니다.

선택 규칙은 평점값과 무관한 고정 해시입니다. 추천 후 입력은 사전 정답과 분리됩니다. 같은 모드의 반복 클릭은 같은 세션을 반환합니다. 모드별 세션·피드백은 분리 저장합니다.

4. 추천 결과 피드백

추천 실행 후 표시됩니다.

5. 추천되지 않은 비교 향수

모델 점수가 아닌 고정 추출 규칙으로 선택한 비교 후보입니다. 경험하지 않았다면 점수를 남기지 마세요. 검색을 통한 추가 평점은 자발적 선택 편향이 있습니다.

6. 평가 완료

응답을 저장하면 완료됩니다. 실제 경험 응답만 선호 분석에 쓰이며 추천 후 피드백을 독립 Offline 정확도로 해석하지 않습니다.
