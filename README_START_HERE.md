## 사용법
1. Codex에서 **새 프로젝트 폴더/저장소**를 연다.
2. 이 ZIP의 **모든 파일을 저장소 최상위(root)**에 넣는다. `AGENTS.md`는 정확히 이 파일명으로 둔다.
3. 실제 원본 향수 데이터는 `data/raw/` 등에 별도로 넣되, **개인정보·라이선스 확인 전 Git에 커밋하지 않는다**. 원본 데이터가 없으면 Codex가 파일을 요청하고 감사/테스트 스캐폴딩부터 만든다.
4. `CODEX_START_PROMPT.md`의 **전체 본문을 Codex에 전송**한다.
5. 첫 감사 결과의 데이터 스키마·매칭 수·평점 0 의미·3/4/5 비교 방식·외부 평가 가능성 등을 확인하고 이후 구현을 진행한다.
